# 🎓 Monitor Inteligente de Editais IFPB

**Encontre oportunidades do Instituto Federal da Paraíba em um só lugar!**

O **Monitor IFPB** é um aplicativo para Windows desenvolvido para facilitar a busca de editais, concursos, processos seletivos e oportunidades acadêmicas nos portais e campi do IFPB.

## 🔎 Funcionalidades

- 🔍 Busca automática de editais em diferentes portais e campi.
- 👨‍🏫 Pesquisa de vagas para professores substitutos e formadores.
- 🎓 Monitoramento de estágios, monitorias e bolsas.
- 📅 Filtros por período de publicação.
- 🏫 Seleção de campus específico ou pesquisa geral.
- 📋 Resultados organizados do mais recente para o mais antigo.
- 🟢 Identificação de novas oportunidades.
- 🌐 Acesso direto aos editais oficiais.
- 📊 Barra de progresso e opção de cancelar ou limpar a pesquisa.

## 💻 Download e instalação

**Compatível com Windows 10 e Windows 11.**

1. Acesse a seção **Releases** deste repositório.
2. Baixe a versão mais recente do `Monitor_IFPB.exe`.
3. Abra o arquivo para iniciar o programa.

✅ Não precisa instalar Python.

✅ Não precisa realizar cadastro.

✅ Basta ter conexão com a internet.

## 🖥️ Como utilizar

1. Abra o aplicativo.
2. Selecione o campus e o tipo de oportunidade.
3. Escolha o período desejado.
4. Clique em **Executar Varredura Inteligente**.
5. Aguarde os resultados.
6. Dê dois cliques no edital para acessar a publicação oficial.

## ⚠️ Aviso importante

Este é um **projeto independente e não oficial**, sem vínculo institucional com o IFPB.

O aplicativo é uma ferramenta auxiliar e não garante a identificação de todos os editais. Consulte sempre os canais oficiais para confirmar informações e prazos.

O executável ainda não possui assinatura digital e poderá apresentar um aviso de segurança do Windows.
